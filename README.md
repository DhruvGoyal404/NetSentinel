# 🚨 Network Anomaly Detection - Real-Time Data Analysis

## 📚 ELC Activity - Semester V

### 🎯 Project Overview
This project implements a **Real-Time Network Anomaly Detection System** using Deep Learning techniques on the **NSL-KDD dataset**. The system detects malicious network activities including DoS, Probe, R2L, and U2R attacks.

## 📊 Dataset Information
- **Dataset:** NSL-KDD (Network Intrusion Detection)
- **Source:** [Kaggle - NSL-KDD Dataset](https://www.kaggle.com/datasets/hassan06/nslkdd)
- **Training Samples:** ~125,973 records
- **Test Samples:** ~22,544 records
- **Features:** 41 features (Textual + Numerical)
- **Attack Types:** Normal, DoS, Probe, R2L, U2R
